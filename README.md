# MORO — Sartoria Italiana · Tashkent

**MORO — премиальная мужская одежда из Италии.** Многоязычный сайт бутика в Ташкенте.
Статический: HTML + CSS + ванильный JS, без сборки и зависимостей — заливается
на любой хостинг, GitHub Pages, Netlify или Vercel как есть.

## Языки

Шесть локалей с переключателем в шапке и в мобильном меню:

| Код | Язык | Направление |
|-----|------|-------------|
| `en` | English | LTR |
| `it` | Italiano | LTR |
| `fr` | Français | LTR |
| `ru` | Русский | LTR (по умолчанию) |
| `uz` | Oʻzbekcha | LTR |
| `ar` | العربية | **RTL** |

Язык определяется в таком порядке: `?lang=xx` в адресе → сохранённый выбор в `localStorage`
→ язык браузера → русский. Выбор запоминается между страницами.
Для арабского автоматически включается `dir="rtl"` и другая пара шрифтов (Amiri / Noto Sans Arabic).

## Структура

```
moro/
├── index.html  about.html  collection.html  concept.html  contact.html
├── serve.js                  # локальный сервер для разработки (без зависимостей)
└── assets/
    ├── css/style.css         # вся вёрстка и дизайн-система
    ├── js/
    │   ├── translations.js   # все тексты, 6 локалей
    │   ├── data.js           # каталог, контакты, ссылки на соцсети
    │   └── site.js           # i18n, слайдер, фильтры, меню, формы
    └── img/
        ├── hero/  editorial/  product/
        └── favicon.svg
```

## Запуск локально

```bash
node serve.js
```

Откроется на `http://localhost:5173`. Порт можно задать: `node serve.js 8080`.

## Как менять контент

- **Тексты** — `assets/js/translations.js`. Ключи одинаковые во всех шести локалях;
  в разметке они подключаются через `data-i18n`, `data-i18n-html` (можно теги),
  `data-i18n-ph` (placeholder) и `data-i18n-aria`.
- **Каталог** — `assets/js/data.js`: категория, материал, метка «новинка».
  Название товара берётся из ключа `p.<id>` в переводах, картинка — `assets/img/product/<img>.jpg` (3:4).
- **Телефоны, адреса, соцсети** — `data.js` и блоки футера в HTML.

## Что стоит доделать перед продакшеном

- Формы (подписка и заявка) сейчас только валидируются на клиенте и показывают
  подтверждение — нужно подключить приём заявок (почта, Telegram-бот или CRM).
- Ссылки «Политика конфиденциальности» и «Условия» — заглушки `#`.
- Цены не указаны намеренно: везде «Цена по запросу».
- Изображения — JPEG; при желании можно добавить WebP/AVIF и `srcset`.
